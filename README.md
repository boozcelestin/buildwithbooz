# 02_Website

## Purpose

The `02_Website` folder contains the strategy, structure, copy, user experience, and ongoing evolution of the BuildWithBooz website.

It serves as the single source of truth for how BuildWithBooz presents itself online and how visitors move from first impression to qualified inquiry.

Every document in this folder should answer one primary question:

> How should the BuildWithBooz website communicate, persuade, and convert?

The website is not merely a digital brochure. It is a sales system designed to explain the offer, establish credibility, qualify prospects, and guide the right visitors toward an Automation Assessment.

# Core Website Philosophy

The BuildWithBooz website should prioritize clarity, credibility, and conversion.

The website should:

- Make the customer’s problem immediately understandable
- Explain what BuildWithBooz does without unnecessary jargon
- Present the Automation Assessment as the primary entry offer
- Show business outcomes rather than technological novelty
- Qualify serious prospects
- Avoid unsupported claims, fake proof, and inflated metrics
- Maintain a consistent visual and verbal identity
- Make the next action obvious
- Reduce friction without oversimplifying the offer

The website should reflect the assessment-first model:

1. Identify the operational problem
2. Diagnose the cost of the problem
3. Recommend the right systems
4. Implement only what the business actually needs
